# J8 STUDIOS

Editorial fitness photography. Winchester.

Marketing site for physique, studio and confidence shoots. Request a studio — no instant booking, no payment on the site.

## Pages

- `/` Home
- `/work` Work
- `/book` Request a shoot
- `/contact` Contact

## Book flow

Studio → weekday/weekend → month → name / Instagram → request.

Prices include studio hire. A £50 hold secures the date after confirmation.

Set `REQUEST_EMAIL` (and optionally `REQUEST_WEBHOOK_URL`) to receive requests.
